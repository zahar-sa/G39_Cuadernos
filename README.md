# G39_Cuadernos

# 📊 Modelos Estadísticos y Distribuciones de Probabilidad

## Enriquecimiento Didáctico de Notebooks Interactivos

Este repositorio contiene una colección de **notebooks de Jupyter** enriquecidos con contenido teórico y código interactivo para el aprendizaje de **variables aleatorias discretas y continuas**, así como los fundamentos de **inferencia estadística**.

---

### 📚 Contenido del Repositorio

| Módulo | Distribuciones / Temas |
|--------|------------------------|
| **Variables Discretas** | Bernoulli, Binomial, Binomial Negativa, Geométrica, Hipergeométrica, Poisson, Uniforme Discreta |
| **Variables Continuas** | Uniforme Continua, Normal, Exponencial, Gamma, Beta, Weibull, t-Student, F de Snedecor, χ² |
| **Inferencia Estadística** | Esperanza Matemática, Momentos, Función Generadora de Momentos, Función Característica, Teorema Central del Límite |

---

### ✨ Características

- ✅ Teoría clara con tablas y analogías
- ✅ Código interactivo con `ipywidgets`
- ✅ Visualizaciones dinámicas (sliders, gráficos actualizables)
- ✅ Ejemplos prácticos y ejercicios propuestos
- ✅ Explicaciones paso a paso

---

### 🚀 Cómo usar

1. Clona el repositorio
2. Abre los notebooks con Jupyter Notebook, JupyterLab o VS Code
3. Ejecuta las celdas en orden
4. Interactúa con los sliders para explorar las distribuciones
